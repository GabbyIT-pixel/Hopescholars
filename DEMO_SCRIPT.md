# Hope Scholar: 4-minute demo video script

Record your screen with your voice (Zoom, Loom or the built-in screen recorder). Speak slowly and clearly, in a quiet room, and check the audio before you submit. Use the live URL if you have one.

**0:00 Introduction (20 s)**
"Hello, I'm Gabriel Mugisha. This is Hope Scholar, a web platform that helps students from underserved communities find scholarships in one place. The problem: scholarship information is scattered, students can't tell which ones fit them, and they miss deadlines. Hope Scholar solves discover, match, save, remember and track."

**0:20 Home and search, no account needed (30 s)**
Open the home page. Click *Browse open scholarships*. Search "health", then use the Field, Level, Country and Deadline filters. Open one scholarship and show the details. (FR 3.1 to 3.3)

**0:50 Sign up and profile (35 s)**
Click *Sign up*, create a student account (show the password rules). Fill the profile: Undergraduate, Computer Science, Rwanda, High need. (FR 1.1, 2.1)

**1:25 Matching and recommendations (35 s)**
Open the dashboard: show "Recommended for you" with match percentages. Open a scholarship and read the "Why it matches" reasons. (FR 4.1, 4.2)

**2:00 Save, remind and track (40 s)**
Click *Save scholarship* with a 7-day reminder. Show the Saved page and the Alerts page (a reminder appears for close deadlines). Set the status to *Applied*, add a note, and show the Applications tracker. (FR 5.1 to 5.3)

**2:40 Administrator (45 s)**
Log out, log in as the admin. Show the review queue: verify the pending listing, then show it appears for students. Show Manage listings (deactivate/edit) and the **Audit log** with logins and admin actions. (FR 6.1, 6.2)

**3:25 Security (25 s)**
"Security is built in: hashed passwords, lockout after repeated failures, CSRF protection, role-based access control, and an audit trail. As a student, if I try to open the admin page I get Not allowed." (Type /admin while logged in as a student.)

**3:50 Close (10 s)**
"The code is public on GitHub with setup instructions, and the live site is at <your URL>. Thank you."
